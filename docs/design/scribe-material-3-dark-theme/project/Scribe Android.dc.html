TITLES · four-part fix

Date and time drop to a metadata line. On stop you get one optional prompt; skip it and the row reads Untitled meeting with an inline rename, until the first transcribed sentence drafts a real title you can overwrite.

TYPE · serif as the chrome

Source Serif 4 at every size, including labels and buttons — set as fontFamily on the M3 text appearances. The M3 type scale, spacing and touch targets are untouched, so the layout still maps 1:1 to stock widgets.

BUILD · stock widgets only

MaterialToolbar, SearchBar, MaterialCardView, Chip, LinearProgressIndicator, ExtendedFAB, BottomSheet, MaterialAlertDialog, NotificationCompat with CATEGORY_TRANSPORT. The level meter is the only custom View.

ASSUMED · unanswered

Audience read as software engineers: real numbers on screen (MB, model name, n/m), no reassurance theatre. Export is .txt + .srt + raw .m4a. Cyan is interactive, magenta means only “the mic is live”.
